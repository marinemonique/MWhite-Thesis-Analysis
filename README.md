# MWhite-Thesis-Analysis
Monique J White Masters of Marine Biology Thesis Analysis

R markdowns are seperated for ease.

Dislodged tiles were removed, but the code to determine whether they would be included or not is found in X.

02_Model_selection has all models ran, including the assessment of DHARMA residuals.

03_Figures.Rmd has all code required to generate figures 2-X.

04_Tables.Rmd has code required for Tukey tests.

05_Summary_statistics.Rmd has code required to get mean and standard error of raw data.
